# yg-chess

Шатрын хувийн дасгалжуулагч. `index.html`-ийг хөтчөөр нээхэд хангалттай, суулгах зүйлгүй. Stockfish болон тактикийг интернэтээс татдаг. Явц тухайн хөтчид хадгалагдана.

- **Гараа:** 39 хувилбарыг судалж, зайтай давтана.
- **AI-тай тоглох:** Stockfish-тэй 8 түвшинд тоглоно. Гараанаас эхэлж, дасгалжуулагчаар алдаагаа тухай бүрт харж болно.
- **Шинжилгээ:** Тоглолт эсвэл PGN-ийг нүүдэл бүрээр үнэлж, алдааг тайлбарлана.
- **Тактик:** Lichess-ийн сангаас бодно. Өөрийн тоглолтын алдаа мөн энд давтагдана.
